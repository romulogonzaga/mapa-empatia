# romulogonzaga.github.io-mapa-empatia
O Mapa de Empatia é uma ferramenta visual para organizar descobertas sobre o usuário. Ele divide a análise em seis áreas. Ferramenta utilizada na unidade curricular "Projeto de Inovação: Modelagem de projetos – Design Thinking e Canvas" do curso de Informática para Internet.
